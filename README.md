# Karl-Johan Bailey

I'm a **software engineer and technical builder** Swedish born to Jamaican parents. I code because I genuinely enjoy understanding how things work and building systems from scratch. My interests span **AI, distributed systems, cloud infrastructure, payments and monetization, streaming, data, 3D, and game technology**. Lately I've been exploring problems around revenue reconciliation, billing systems, advertising, Stripe integrations, data processing, and systems architecture, while also building projects in **Go and C++** to go deeper into backend and lower-level engineering. For fun, I built **Clash of Pirates: War** in Unity and released it on iOS, partly as an excuse to explore game development, mobile optimization, analytics, and **Google AdMob**, but mostly because I genuinely love making games. I'm also interested in video processing, depth estimation, segmentation, and finding ways to turn raw data into structured representations. I enjoy moving between high-level applications and the systems underneath them, and if I encounter an interesting technical problem, there's a good chance I'll try to build it myself.
