## Eislett Technologies

I'm building **Eislett Technologies**, where I'm focused on creating software products around education, AI, and technology.

### Is-Ed

One of my main projects is **Is-Ed**, an EdTech platform focused on making education more interactive and intelligent.

I'm interested in going beyond traditional educational software and exploring how **AI, automation, data, and modern interfaces** can change the way students learn and interact with educational content.

I'm involved across the stack:

* Product development
* Software architecture
* AI integration
* Backend systems
* Web applications
* Infrastructure
* Automation
* Data
* Deployment and scaling

Is-Ed is ultimately an experiment in answering a question:

> **What could education look like if we built it around the technology available today instead of the technology we had 20 years ago?**

## My Journey Into AI

My interest in AI didn't start with the current wave of generative AI.

I first became heavily interested in **AI automation**—using software to automate processes that would traditionally require people to manually interpret information, make decisions, or move data between systems.

Since then, I've worked extensively with modern AI systems and have developed an understanding of how applications built around **LLMs, agents, automation, speech, and real-time AI** can actually be engineered.

I'm particularly interested in the engineering side of AI:

* LLM application architecture
* AI agents
* Prompt and context design
* Tool calling
* Retrieval and data pipelines
* Speech and transcription
* Real-time AI
* AI automation
* API orchestration
* Model integration
* Building AI into actual products rather than just demos

I'm less interested in AI as a buzzword and more interested in **what we can actually build with it**.
